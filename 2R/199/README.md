# Overview

This document describes model 2R build 199.

Run the model using Python G-Cubed version 5.0.1.4.

The database and IO tables are generated by version 1.0.0.4 of the G-Cubed data system.

The comparison build is `2R/198`.

## Unemployment reporting input

With the Python G-Cubed version declared above, the `UNRATE` derived variable
reads the single model-local
`data/unemployment_model_parameters.csv` file. `unrate_initial` and
`unrate_equilibrium` are mandatory; the eight recognized parameter rows are
optional and omitted parameters default to zero in every region. Rows are
loaded by name rather than position, although this build writes the initial
and equilibrium rows first and second. See the
[unemployment-rate model guide](../../docs/Understanding%20the%20unemployment%20rate%20model.md).

## Changes since the 198 build

Build `2R/199` is a versioned replication of `2R/198` that
preserves the capital-stock, rate-of-return and capital-emissions changes
implemented through the
[capital stock and rate-of-return TDD plan](../../developer-documentation/completed/capital-stock-rate-of-return-tdd-plan.md).

Runtime ownership is implemented through the
[runtime-derived capital returns TDD plan](../../developer-documentation/completed/runtime-derived-capital-returns-tdd-plan.md).

- Source data generation derives one common regional standard/Y return from
  GTAP-reference-year capital services and raw mapped `VKB`, then applies that
  source-derived rate to accepted annual services. The former 2.5-times-GDP
  floor is not applied; a region-specific warning is issued when raw `VKB` is
  below twice final-IO GDP.

- Every annual household-sector Z stock is an independent snapshot equal to
  final reconciled IO GDP times the same-year resolved, GDP-weighted WID
  `nwhou` housing-and-underlying-land ratio. Z remains outside the
  standard-plus-Y `VKB` reconciliation. `INVZ` is unchanged and adjacent-year
  stock-flow closure is diagnostic rather than imposed.

- The `base_rate_of_return_on_capital*` parameters remain declared in SYM, but
  the base rates are derived at runtime from the model-base-year database and IO tables.
  `data/user_parameters.csv` must not contain those runtime-derived rows. The
  runtime calculation fails closed for missing, non-finite, or non-positive
  services, GDP, or capital stocks and writes
  `diagnostics/capital return calibration.csv`.

- Annual capital construction evidence remains in the data repository's
  `capital stock construction.csv` diagnostic. Model builds no longer carry
  `capital_services_in_all_database_years.csv` or a script that reverses the
  ownership by updating capital stocks from editable return parameters.

- The source-stock Z return uses GTAP-reference-year WID stock and IO services.
  The model's scalar Z return is derived independently from model-base-year
  database stock and IO services.

- Direct total wealth values both special capital sectors using
  `LAMY * CAPY + LAMZ * CAPZ`, matching the active SYM equation.

- Standard-sector capital-emissions intensities are calibrated against capital
  services, `base_rate_of_return_on_capital * CAP`, rather than capital stock
  alone. The multiple-GHG linear and positive-intensity log equations use the
  same service activity.
